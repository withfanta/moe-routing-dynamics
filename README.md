# moe-routing-dynamics

Private research repository for the sparse-MoE routing-dynamics project.

- `preprint/` will contain manuscript material later. It is intentionally empty for now.
- `code/` contains reproducible experimental records: protocols, source code, tests, and
  frozen result files for each experiment in the line.

The repository is private and under active research. Scientific claims live with the
individual experiment records under `code/`, not here.

`.gitkeep` files are intentional: git cannot track empty directories.
